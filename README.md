# 温度监控数据分析工具

用于分析温度传感器导出的 CSV 数据，计算超温/低温报警时段并生成报告。

## 功能

- **多文件加载**：支持同时加载多个 CSV 文件，自动合并去重排序
- **阈值计算**：设置高温/低温阈值，计算超出阈值的时间段（精确到分钟）
- **多区间分析**：一次输入多个时间区间，分别生成报告
- **MKT 计算**：平均动力学温度（Mean Kinetic Temperature），用于药品冷链评估
- **Excel 导出**：每区间一个 Sheet，含信息汇总表、报警明细表、统计信息
- **脱敏日志**：日志中不记录任何具体温度数据，保护机密信息

## 截图参考

输出报告包含三部分：

### 信息汇总
| 序号 | 状态 | 持续时间 | 时间占比 | 报警次数 |
|------|------|----------|----------|----------|
| 1 | 温度正常 | 19天9小时39分钟 | 99.6% | — |
| 2 | 高温报警 | 1小时54分钟 | 0.4% | 11 |
| 3 | 低温报警 | 0分钟 | 0.0% | 0 |

### 报警明细
| 序号 | 开始时间 | 结束时间 | 类型 | 时长 |
|------|----------|----------|------|------|
| 1 | YYYY-MM-DD HH:MM | YYYY-MM-DD HH:MM | 高温报警 | 12分钟 |

### 统计信息
- 开始/结束时间、累计时长
- 温度最大值/最小值/平均值
- MKT（平均动力学温度）
- 数据条数

## CSV 数据格式

文件编码：GBK 或 UTF-8（自动检测）

列结构：

| 列名 | 说明 | 示例 |
|------|------|------|
| 部门 | 设备所属部门 | — |
| 设备名称 | 传感器设备名 | — |
| 采集器编码 | 设备编码 | — |
| 传感器名称 | 传感器类型 | 温度 |
| 数据 | 温度值（含℃后缀） | XX.X℃ |
| 时间 | 采集时间 | YYYY/MM/DD HH:MM |

## 使用方法

### 方式一：直接运行（需 Python 环境）

```bash
pip install openpyxl
python src/main.py
```

### 方式二：打包为 Windows 可执行文件

```bash
pip install openpyxl pyinstaller
pyinstaller build.spec
```

生成的 exe 文件在 `dist/` 目录下。

### 操作步骤

1. 点击「选择CSV文件」，加载一个或多个数据文件
2. 设置高温阈值、低温阈值（MKT 活化能默认 83.144 kJ/mol，可修改）
3. 添加计算区间（输入开始和结束时间，格式 `YYYY-MM-DD HH:MM`）
4. 点击「开始计算」，结果在下方 Tab 页展示
5. 点击「导出Excel」保存报告

## 计算规则

- **阈值判断**：严格超出才算报警（温度 > 高温阈值 为高温报警，温度 < 低温阈值 为低温报警，等于阈值不算）
- **时间精度**：取采样点时刻，不做插值
- **分段逻辑**：从第一个异常点开始，到第一个恢复正常点结束，算一段区间

## 日志说明

日志文件位于程序同目录 `logs/` 下，按日期滚动（`app_YYYYMMDD.log`）。

日志中**不记录**以下内容：
- 具体温度数值
- 具体数据时间戳
- 设备序列号、部门名称等敏感信息

日志中**记录**以下内容：
- 文件加载情况（文件名、行数）
- 计算过程（区间数量、报警次数、总时长）
- 错误信息（解析失败行号及原因）
